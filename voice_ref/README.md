# voice_ref/

Sophie's voice is cloned from `sample.wav` in this folder.

- `python scripts/download_default_voice.py` fetches a public-domain default (LJSpeech).
- Or use your own: 5-20 seconds of one person speaking clearly, no music or background noise.

Only use a voice you have the right to use, with the speaker's permission.
Everything in this folder except this README is git-ignored.
